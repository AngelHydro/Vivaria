- 3 types d'entités (plantes, herbivores, carnivores)
- Déplacement aléatoire des animaux
- Herbivores mangent plantes (même case = consommation)
- Carnivores mangent herbivores (même case = consommation)

- Système d'énergie :
  - Manger = gain d'énergie
  - Vivre = perte continue d'énergie
  - 0 énergie = mort
    - Mort par famine OU vieillesse
  - Reproduction si énergie suffisante
  - Cycle de croissance des plantes (repoussent naturellement)


Interface Base
- Affichage grille de simulation (entités = cercles colorés)

- Stats temps réel dans les coins :
  -🌱 Nombre de plantes
  -🐰 Nombre d'herbivores
  -🦁 Nombre de carnivores
  -⏱️ Temps écoulé (en jours simulés)

- Bouton ▶️ Play / ⏸️ Pause
- Bouton 🔄 Reset (réinitialise tout)

- Sélection de 4 biomes :
  -🌲 Forêt
  -🌾 Plaine
  -🏜️ Désert
  -❄️ Toundra

Environnement Dynamique
- Système météo (4 options) avec effets sur croissance plantes :
  -☀️ Soleil (croissance normale)
  -🌧️ Pluie (croissance +50%)
  -⛈️ Orageux (croissance -20%)
  -❄️ Neige (croissance -50%)

- Système saisons (4 options) avec effets sur reproduction :
  -🌸 Printemps (reproduction +50%)
  -☀️ Été (reproduction normale)
  -🍂 Automne (reproduction -20%)
  -❄️ Hiver (reproduction -50%)

- Impacts mécaniques des biomes (pas seulement visuel) :
  -🌲 Forêt : Croissance plantes +20%, vitesse animaux -10%
  -🌾 Plaine : Équilibré (baseline), vitesse animaux +10%
  -🏜️ Désert : Croissance plantes -50%, coût énergie +20%
  -❄️ Toundra : Reproduction -30%, croissance plantes -20%
